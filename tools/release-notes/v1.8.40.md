# v1.8.40：找到了 —— 你用的是 **WPS 演示**，它的窗口类叫 PP12FrameClass

## 为什么前两版都没生效

我一直在按微软 PowerPoint 的窗口类（PPTFrameClass）做适配。
但你机器上开着的是 **WPS Office**（D:\software\WPS Office\...，窗口标题「4.3课件.pptx - WPS Office」），
它的窗口类实测是：

`
class = PP12FrameClass
`

和 PPTFrameClass 只差一个字母，所以 v1.8.38 / v1.8.39 的适配**一次都没命中**，
它仍然被当成"按比例滚动"——一格被拆成十几个事件，一页一页地翻过去。

## 这一版

新增 IsPpFrameClass：PP + 数字 + FrameClass（覆盖 PP11 / PP12 / PP14 / PP15 等版本），
同时加入"按事件滚动"和"不读系统行数"两个判据：

| 判据 | 效果 |
|---|---|
| 按事件滚动 | 一格只发**一个**事件 |
| 不读系统行数 | 细腻模式**不做 ×3 补偿** |

于是：**滚一格 = 一个事件 = 翻一页**，和没装本软件时一致。

## 新增 --targettrace（这次靠它定位）

`
MouseWheelEnhancement.exe --targettrace
`

20 秒采样，把每个滚轮事件的判定写成 	argettrace.txt：

`
deepseek harness.exe | Chrome_WidgetWin_1 | raw=-120 fine=1 | boosted=False mult=1.00 out=-120 | whole=0 self=1 ignoreLines=0
`

字段依次是：进程、窗口类、原始 delta、细腻倍数、是否加速、倍率、输出单位、
是否按事件、是否自带平滑、是否不读系统行数。以后任何"某个程序滚动手感不对"，
跑一次这个就能直接定位到是哪条判据错了。
