# v1.10.0：把 SmoothScroll 的「脉冲曲线」和「帧同步」搬进来

## 怎么来的

把 SmoothScroll（Windows 上那款付费平滑滚动）的本体拆开看了一遍：
它的发帧函数每个垂直消隐期跑一次 `SendInput`，曲线是一条很特别的
**脉冲曲线** —— 起手速度为 0、中段接近匀速、尾部指数软着陆。本项目原来
四种曲线全是"第一个发帧就冲出去、然后收住"，缺的正是这一族手感。

## 新增：脉冲曲线

「平滑」页的曲线下拉多了「脉冲（推荐）」，并配一个**脉冲强度**滑块：

- 强度越大，缓起段越短、起步越急（4 = 用前 25% 的时间缓起，与 SmoothScroll 一致）；
- 强度越小越绵（2 最绵，8 已经很直接）。

同样滚一格 120 单位，实测峰值单帧步长：脉冲 9 单位、五次 18 单位、指数 12 单位。
**摊得最匀**，这是它看起来最"顺"的原因。

## 新增：帧同步

每个发帧前先 `DwmFlush()` 等一次显示器的合成帧，让每一小步都落在自己那一帧里。
本机实测合成帧间隔 6.26 ms（目标 6.25），标准差 0.23 ms。

只在「自动跟随显示器刷新率」时生效；DWM 跟不上（全屏独占、远程桌面）时会自动
退回原来的高精度定时器，日志里留一条 warn。不需要就关掉。

## 默认值：全新安装直接用新方案

| 场景 | 模型 | 曲线 | 单格时长 | 帧同步 |
| --- | --- | --- | --- | --- |
| 全新安装（没有 config.json） | 逐格缓动 | 脉冲 | **160 ms** | 开 |
| 升级（已有 config.json） | 一个字节都不动 | | | |

**老用户的手感不会被升级改掉**。想试新的，在「平滑」页选「逐格缓动 + 脉冲」。

160 ms 是量出来的，不是抄 SmoothScroll 的 360 ms：脉冲在 220 ms 下单格要 233 ms、
落地段 50 ms，用户会觉得"松手了还在滑"；160 ms 下单格 171 ms、落地段 31 ms，
比五次曲线只慢 16 ms，但首帧只有 2 单位（五次是 18）。

## 命令行对比三种手感

```
MouseWheelEnhancement.App.exe --frametrace decay     # 指数衰减
MouseWheelEnhancement.App.exe --frametrace eased     # 逐格缓动（配置文件里的曲线）
MouseWheelEnhancement.App.exe --frametrace pulse     # 脉冲
MouseWheelEnhancement.App.exe --frametrace vsync     # 带帧同步，顺便量显示器周期
```

报告写在 `Mouse wheel enhancement data\frametrace.txt`。
