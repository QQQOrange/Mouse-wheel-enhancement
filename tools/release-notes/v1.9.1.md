# v1.9.1：最近识别的程序（概览页）+ 每应用手感覆盖

## 1. 概览页新增「最近识别的程序」

每个程序用的是哪种滚动语义，现在一眼可查：

`
deepseek harness.exe
Chrome_WidgetWin_1                     自带平滑 · 42 次（加速 17）
POWERPNT.EXE
PPTFrameClass                          按事件·不读行数 · 8 次
`

- 最多显示 6 条，按最后出现时间排序；
- 统计是**本机内存里的**，不联网、不落盘；
- 手感不对时先看这里：显示"按事件"的程序不能摊帧，"自带平滑"的要交还给应用。

## 2. 每应用手感覆盖

名单里右键任意程序 → **手感（跟手 τ / 惯性）**：

| 预设 | 参数 |
|---|---|
| 跟手 | τ 16ms / 惯性 200ms |
| 标准 | τ 30ms / 惯性 420ms |
| 悠长 | τ 45ms / 惯性 600ms |

原来覆盖只能改倍率上限 / 平滑开关 / 滚动语义，现在 τ 和惯性也能按程序定 ——
游戏里要脆、文档里要顺、终端里要跟手，不用再全局来回切。
