# v1.8.15：重做之后的收尾自审 —— 修 3 个真 bug，「惯性长度」终于有用

v1.8.14 换了 Mos 的模型之后，我把整条链路重新过了一遍。这一版全是修复。

## 1. 「惯性长度」滑块之前是死的（真 bug）

v1.8.14 里收尾 τ 是按"让积压恰好在 GlideMs 内排空"反解的，而结果又被**跟手下限（45ms）**夹住 ——
180ms 默认值下几乎永远夹住。也就是说：**你拖那个滑块，手感一点变化都没有。**

现在改成**比例映射**（ReleaseTau）：180ms = 跟手 τ（默认），400ms → 约 2.2 倍（尾巴更飘），
60~100ms → 收得更干脆。滑块拖到哪，尾巴就多长，所见即所得。

## 2. 亚像素残量会让动画线程永久空转（真 bug）

"死区"分支里，当积压只剩 **不到半个单位**（0.4 单位 = 0.2px）时：
这一帧算出"该发 1 单位"，而 TakePending 只能扣整单位 → 扣不掉 → 下一帧重复，
**动画线程以帧率空转到天荒地老**（还让钩子的 PendingUnits != 0 判定一直为真）。
现在残量为 0 时直接丢弃并停。

## 3. 自检在测已经不存在的代码（审计发现）

v1.8.14 删掉了「落地段插值」「尾段 ln 定时」「GlideTau」这三套逻辑，
但自检里还留着它们的仿真和断言（MaxFinishMs、TailGapMs、LandingStartUnits…）——
**跑着绿，守的却是上一版的实现**。这一版：

- SimulateTimed 逐行对齐线上主循环（低通 + 死区 + 补齐）；
- 删掉尾段/落地段/GlideTau 的断言，换成 ReleaseTau 的 6 条；
- 清掉 _pushRateMilli / _lastPushTicks / 尾段常量等死字段。

自检从 356 条变成 **347 条**（删掉的都是"测死代码"的那些），覆盖反而更实。

## 验证

--selftest **347 项全过**；--featurecheck、--frametrace（含 jitter）、--scrollsmooth、
--smoke、--measure 全 rc=0。160Hz 实测：滚一格 171ms、三格 236ms、六格 264ms，
末三帧 1/1/2 单位（每帧 6ms 均匀收敛），末步空窗 6.6ms、0 次速度回跳。
