# v1.9.13：修掉「没滚滚轮也一直显示倍率」的浮层

这一版只做一件事：让倍率浮层（OSD）**该出现时出现、该消失时一定消失**。

## 现象

用户反馈：没有滚动滚轮，鼠标旁边却一直挂着一个显示倍速的胶囊标签。

## 两个独立成因

1. **高精度输入把它续命了。**
   触控板、自由滚轮、部分鼠标的触摸表面发出的不是「一格 120」，而是 60–125 Hz 的连续小步。
   每一小步都足以让速度超过 1.5× 的显示阈值，而 `NotifyBoosted` 每 120 ms 就允许刷新一次，
   于是浮层被一路续命，看起来就是常驻。
   修法：`NotifyBoosted` 增加 `precisionInput` 参数，高精度流只走加速/平滑，不再显示倍率浮层 ——
   它本来解释的是「这一格为什么滚得远」，而高精度流没有「格」这个概念。

2. **淡出收尾只有一条路。**
   原来的收尾是「淡出动画完成 → 回调里检查 `Opacity <= 0.01 && IsVisible` → `Hide()`」。
   只要动画被打断、回调抛异常，或 `Opacity` 因故没有归零，`Hide()` 就不会执行，
   而 `_hide` 定时器已经停了 —— 窗口永久留在屏幕上。
   修法：
   - `Flash()` 整体包 try/catch，显示过程中任何异常都强制收起；
   - 新增 `HideNow()`：停表、清动画、`Opacity = 0`、`Hide()`，不依赖动画状态；
   - 新增 250 ms 看门狗 `_guard`：最后一次 Flash 之后超过「停留 520 ms + 余量 600 ms」
     仍未隐藏，就强制收起并记一条 WARN。

## 新增诊断

- `--osdcheck`：显示 → 连续 Flash 6 次（模拟快速连滚）→ 空转 1.6 s，
  断言窗口已隐藏且 `Opacity` 归零。任何一条收尾路径坏掉都会失败。

## 验证

- `--osdcheck`：`显示后 visible=True opacity=1.00` → `1.6s 后 visible=False opacity=0.00`，退出码 0。
- `--selftest`：497 项全过。
- `--featurecheck`：全过（含逐格缓动用例）。
