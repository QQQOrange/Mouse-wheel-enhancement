# v1.9.3：细腻模式退出还原 —— 加一个独立守护进程

## 你报的问题

> 系统本来是一次滚三格，软件运行期间变成一格；退出后没有改回三格。

这是真问题。原来只有三条还原路径：正常退出（ProcessExit）、关机/注销（SessionEnding）、
下次启动（CleanupFine + RunOnce）。**强制结束 / 被杀 / 崩溃**这三条都不走 ProcessExit，
于是系统会一直停在 1 行，直到下次登录。

## 这一版

新增 --fineguard <pid> <lines> 守护进程：

- 进入细腻模式时由主程序启动，**独立进程**；
- 主进程怎么死（任务管理器结束、崩溃、关机）都不影响它；
- 它等主进程退出，然后把行数写回去，再自己结束。

另外新增配置项 ehavior.fineRestoreLines（0 = 用进入前记录的原值，1~10 = 写死为指定行数），
运行时同步到 SystemWheelLines.RestoreTarget。

## 还原路径现在有四条

| 场景 | 由谁还原 |
|---|---|
| 托盘退出 / 关窗口 | 主进程（引擎 Dispose） |
| 关机 / 注销 | SessionEnding 回调 |
| 强行结束 / 崩溃 | **守护进程**（新增） |
| 进程来不及（蓝屏/断电） | 下次启动的 CleanupFine + RunOnce |
