# v1.8.38：PPT 里滚一下翻两页 —— PowerPoint 被归错了滚动语义

## 现象

在 PowerPoint 里滚一格，幻灯片从第 1 页直接跳到第 3 页。

## 原因

PowerPoint 的窗口我们之前按「按比例滚动」处理（和 Word/Excel 一视同仁），
于是我们习惯性地**把一格拆成十几个小事件**发出去。

但 PowerPoint 的幻灯片视图里，**一个滚轮事件就是翻一页**，完全不看 delta 大小。
十几个事件 = 翻十几页（实际因为合并/节流，你看到的是跳两页）。

这和 WPF / WinForms / Qt 是同一类问题：事件个数被当成了滚动量。

## 修法

把 PowerPoint 归到「按事件滚动」：

| 窗口类 | 说明 |
|---|---|
| PPTFrameClass | PowerPoint 主窗口（幻灯片视图） |
| screenClass | 放映窗口 |

归到这里之后：**一格只发一个事件**（没加速时直接原样放行），
加速时才发 N 个整格 —— 一格永远只对应一步。

Excel（XLMAIN）**不在**此列：它按行滚、认 delta，摊帧是安全的，保持原样。

## 验证

--selftest **370 项**（新增 3 条：PPT 主窗口 / 放映窗口 / 一格只发一格），全过。
