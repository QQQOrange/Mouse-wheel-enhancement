# v1.8.30：一键「触控板级」+ 自检拆成三个文件

## 1. 新按钮：触控板级

平滑滚动页的手感曲线现在有五个预设，多出来的这个是**一步到位**：

> **触控板级** = 16ms 跟手 + 600ms 惯性 + 自动打开细腻模式

之前要手动做三件事（点「触控板」、翻到下面开细腻模式、确认系统设置弹窗），现在一次点完。
它走的是细腻模式原本那条路（同一个 Checked 事件、同一个确认弹窗、同一套还原机制），
没有另起一套逻辑。

顺带修了「顺滑」的提示文字（还写着惯性 300ms，实际默认已经是 420ms）。

## 2. 结构：SelfTest 拆成三个文件

SelfTest.cs **1740 → 101 行**：

| 文件 | 行数 | 内容 |
|---|---:|---|
| SelfTest.cs | 101 | 入口 Run() + Check/Near/Section 断言辅助 |
| SelfTest.Scroll.cs | 822 | 速度曲线、起步护栏、摊帧、滑行收尾、整段模拟 |
| SelfTest.App.cs | 765 | 配置读写、名单匹配、主题、版本号、令牌清洗、布局判据 |

拆分后断言数量不变（**360 项全过**），改哪一块只用打开对应的文件。
