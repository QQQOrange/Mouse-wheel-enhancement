# v1.9.12：可选的「逐格缓动」模型（参考 SmoothScroll）

这一版把 SmoothScroll 的核心手感做成了一个**可切换的动画模型**，并用同一套
`--frametrace` 口径把它和原有的指数衰减模型量了一遍。结论是：默认仍然用指数衰减，
逐格缓动作为选项放在「平滑」页，想要更绵、落点更确定的手感时可以自己切。

## 新模型

- **逐格缓动**：每一格滚轮在固定时长内按选定曲线走完，多条车道叠加，互不重置。
  曲线有五次（默认，SmoothScroll 同款）、三次、指数、线性；时长 80–600 ms，默认 220 ms。
- **指数衰减**（默认）：原来的跟手 τ + 松手惯性，按触控板实测标定；连滚时自然叠加、渐近收尾。
- 「平滑」页新增「动画模型」卡片：切换模型、选曲线、调时长，曲线预览会跟着变成
  对应形状，并在落点处画一条 guide 线（缓动模型标「一格」，指数模型标「τ」）。
- 配置项：`smooth.model`（`decay` / `eased`）、`smooth.easing`（`quintic` / `cubic` /
  `exponential` / `linear`）、`smooth.easedMs`（80–600）。导出/导入配置会自动带上。
- 命令行可覆盖（只改内存，方便对比，不落盘）：`--model eased --easing quintic --easedms 220`。

## 为什么默认不改

同一台 160 Hz 显示器、单帧 90 单位、τ 40 ms 下用 `--frametrace` 对比：

| 场景 | 指数衰减 | 逐格缓动（五次 / 220 ms） |
| --- | --- | --- |
| 单格 | 14 帧 / 93 ms / 中段起伏 1.1× | 21 帧 / 157 ms / 中段起伏 1.6× |
| 3 格 | 111 ms / 单帧最大 34 | 200 ms / 单帧最大 36 |
| 6 格 | 121 ms / 单帧最大 65 | 203 ms / 单帧最大 69 |

逐格缓动的优点是落点时间确定、尾巴形状可选；代价是延迟高 40–70%、帧间起伏更大。
指数衰减在客观平滑度和跟手性上更好，所以默认不动，逐格缓动作为「更绵」的备选。

## 其它

- 英文界面补全了「动画模型」整张卡（说明、两个模型名、四条曲线、时长提示、摘要行），
  曲线预览的 guide 标签也会跟着语言走。
- 自检新增 21 项：四条曲线的端点/单调性/中点值/起手速度/收尾速度、`Parse` 的大小写与
  回退、三个默认值、四条英文文案。
- `--featurecheck` 新增「逐格缓动」用例：360 单位在 220 ms 内分 19 帧发完、首帧 66 单位。
