# v1.8.20：倍率浮层不再"特别宽"，左右留白对齐

## 现象

浮层比文字宽出一大截，右边空着一条，左窄右宽。

## 根因

Window.SizeToContent 会把 DropShadowEffect 的**外扩边界**算进窗口尺寸。
BlurRadius = 18 时每边约 27px —— 卡片自己只有 72px 宽，窗口却被撑到 **131px**，
多出来的 59px 全在右边。文字越短，空得越明显。

## 修法

- 关掉 SizeToContent，改成 **SizeToContent.Manual**；
- 卡片自己留 9px 透明外边距给投影（ShadowPad），窗口尺寸 = 卡片 DesiredSize（**不含**投影外扩），
  每次更新数字时重新量一次 —— 位数变了会跟着变宽变窄；
- 顺带把投影调柔和（BlurRadius 18 → 8、透明度 0.30 → 0.18），之前那圈黑晕在浅色背景上太重；
- 右侧内边距 13 → 14，和左侧"竖条 + 间距"的视觉重量对齐。

实测：窗口 91×52 = 卡片 73×34 + 两侧各 9px 投影区，**没有多余空白**（修前 131×35.5）。

## 验证

--osdshot 重拍深浅两张（整窗渲染，79→91 的尺寸也对得上），逐像素看左右留白；
--selftest 351 项、--featurecheck（浮层三组）、--smoke 全 rc=0。
