# v1.8.18：修好深色主题里"深底黑字"，以及关机/断电后的还原

## 1. 深色主题：整页文字是黑的（真 bug，根因在继承链）

现象：切到夜间模式后，左侧导航是白的，右侧整页文字却是黑的 —— 深底黑字，基本看不清。

根因：页面内容挂在 TabControl 模板里的 ContentPresenter 下，而 Foreground
是从 **TabControl** 继承的（不是从 Window）。TabControl 没设 Foreground，
默认取 SystemColors.ControlTextBrush（浅色主题是黑、**深色主题也是黑**）。
导航栏不在 TabControl 里，所以它是白的 —— 正好是"有的白、有的黑"。

修法：给 TabControl / TabItem 加上隐式样式，把 Foreground 接到
{DynamicResource TextPrimary}。一处修，8 个页面全部生效。

## 2. 关机 / 断电也会还原（细腻模式）

以前只有"正常退出"和"下次启动"两条路。现在补上两条：

- **关机 / 注销**：订阅 SystemEvents.SessionEnding，收到就立刻把行数写回去；
- **硬断电 / 强杀**：进入细腻模式时登记一条 HKCU\...\RunOnce，下一次登录由系统执行
  eg add ... /f & rundll32 user32.dll,UpdatePerUserSystemParameters，
  既改注册表、也广播 WM_SETTINGCHANGE（只改注册表的话，已经启动的浏览器会继续按 1 行算）。
  正常退出时会删掉这条 RunOnce，所以平时它不存在。

还原时**只在"当前值还是 1 行"时才写回**：如果你在细腻模式期间自己去系统设置里改过，
就尊重你的值，只清备份。

实测三条路：正常退出 3→1→3；强杀后停在 1、下次启动还原为 3；RunOnce 命令手动执行后 3。

## 3. 新增诊断命令 --uishot [light] [页码]

逐页把窗口渲染成 PNG（uishot-<theme>-<page>.png，落在数据目录）。
这次就是靠它把 8 个页面在深色下逐页看了一遍 —— 以后改配色也能直接对比，
不用再靠肉眼盯窗口。
