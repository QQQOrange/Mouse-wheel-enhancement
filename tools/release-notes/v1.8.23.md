# v1.8.23：把 App 拆成三个文件，并修掉看门狗的一个漏判

这一版**只搬家 + 修一个真 bug**，没有任何行为变更。

## 1. App.xaml.cs 2600 行 → 三个 partial 文件

| 文件 | 行数 | 内容 |
|---|---:|---|
| App.xaml.cs | 1449 | 启动 / 单实例 / 提权 / 托盘 / 窗口生命周期 / 看门狗 / 退出 |
| App.Diagnostics.cs | ~950 | --smoke、--dialogtest、--uishot、--osdshot、--wheeltest 辅助 |
| App.ScrollPage.cs | ~180 | 设置页自己的 delta → 像素换算与合帧队列 |

用 partial 而不是拆成两个类：这些方法共享 App 的日志、配置、窗口和生命周期状态，
硬拆就得上构造注入或服务定位器 —— 那是更大的改动、更多的新 bug 面，收益只是"类型图好看"。
**搬家的目的是让人找得到代码，不是让架构图好看。**

## 2. 看门狗漏判（真 bug）

诊断看门狗原来用 DiagnosticArgs.Contains(arg) 判定 —— 区分大小写、只认整串：

- --WHEELTEST 不触发看门狗；
- --wheeltest lines=3（带参数）也不触发。

这两种写法仍然会**无声挂死**（之前踩过一次 10 分钟）。现在改成 IsDiagnosticArg：
大小写不敏感，并接受 --flag value / --flag=value。
