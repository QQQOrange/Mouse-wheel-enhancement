# v1.9.6：横向平滑 / 中键拖拽 / UI 基线 / 更新通道

## 1. 横向滚动平滑（Shift+滚轮）

新增独立横向通道：一个 HWHEEL 拆成最多 8 个事件、每约两帧发一个。
独立线程 + 独立队列，**不碰纵向主循环**，最坏情况也只是横向不平滑，不会拖死纵向滚动。

## 2. 中键拖拽平移（默认关闭）

按住中键上下拖 = 连续滚动，每 40px 折算一格，走直通队列（不在钩子里 SendInput）。
配置项 input.middleDragPan。关闭时完全不碰中键。

## 3. UI 像素基线回归

- --uibase：渲染 light/dark × 8 页，存到 	ools/ui-baseline/
- --uicheck：重新渲染并逐像素比较，差异 > 0.3% 判失败，输出热区与 uicheck.txt

## 4. beta / stable 更新通道

配置 updateChannel：stable（默认，取 eleases/latest）或 eta（取 eleases?per_page=20 第一条，含预发布）。
非法值自动收敛为 stable。

## 5. 边界回弹 —— 没有实现

原因：全局滚轮钩子**拿不到目标进程的滚动位置**，无法判断"是否到底"。
唯一可行的做法是启发式（连续同向注入后无位移反馈就假定到底），误判率高、会在正常滚动中间插入回弹。
我不把这种半成品塞进正式版。这项要么找到可靠信号，要么不做。
