## 1. 结构：MainWindow.Settings.cs

MainWindow.xaml.cs **1744 → 1472 行**，把「配置 ↔ 控件」那一整块搬进新文件：

- *_Changed 处理器（总开关、平滑、惯性、阈值、每格帧数、应用名单、主题……）
- SyncWheelLinesFromSystem / RefreshWheelLinesLabel / UpdateThemeHints

它们共享同一条流水线（读控件 → 写配置 → Commit()），也共享同一条约定 ——
每个方法第一行都是 if (_loading) return;（防止程序化赋值触发回调）。
把这条约定集中在一个文件里，比散落在 1700 行中更不容易写漏。

## 3. 一处自我否决（记录在案）

本来想给 --scrollsmooth 加一条"每格位移偏差 ≤ 20%"的硬判据（前一阵出现过一次
8 格滚了 1235px 而不是 705px 的异常）。写完发现：

- App.PixelsPerLine 是 **20**，而页面实际每行约 **29.3px**（系统行高不是常量），
  这条判据会天天误报；
- 正确的比较基准应该是"同一台机器上先跑一次基准值"，属于更大的改动。

所以这条判据**撤回了**，没有把误报留在代码里。异常本身仍待复现。
