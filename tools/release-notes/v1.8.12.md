# v1.8.12：全盘自审 —— 修 12 个真 bug，按应用覆盖终于接通

这一版**没有新功能**，全部是"本来应该是这样"的修复。下面每条都能对上自检或实测。

## 一、功能接好了线却没生效的三处

**1. 按应用覆盖在默认（黑名单）模式下永远不生效。**
覆盖挂在名单条目上，而"名单里的不增强"先把那个程序排掉了 —— 连滚轮都不经过本程序，覆盖参数当然用不上。现在覆盖是**正向声明**：设了覆盖的程序在两种模式下都增强。
（判据还修了一处：覆盖快照是在 PerApp 字典填好**之前**派生的，它手里那份字典是空的 —— 用 `ContainsKey` 判断永远为假，这是它一直不生效的另一半原因。）

**2. 覆盖里的「平滑关」只改了字段，没改出帧。**
动画器只认全局快照。现在每次投递都带上"这一下的有效设置"，单帧容量、积压上限、平滑、滑行全按覆盖走。

**3. 名单页右键菜单的两个子菜单根本打不开。**
`MenuItem` 的控件模板里没有 `PART_Popup` / `ItemsPresenter`（子菜单就靠它们承载），「倍率上限」「平滑」十二个选项永远显示不出来。模板已补齐，并加了勾选字形与子菜单箭头。

## 二、会让整个程序"用不了"的三处

**4. 平滑动画线程异常退出 → 全系统滚轮不动。**
线程死了 `_alive` 不落、`Start()` 拒绝重启，而钩子还在把每个事件吞下来（默认「所有滚动」）—— 吞了没人发。现在：finally 落标记、钩子发现动画器不在就**原样放行**、看门狗负责重新拉起。

**5. `Clear()` 与出帧的"读→减"不配对，积压会变负。**
负数积压让比例模式反向发一点（"快滚后回退一下"）、整格模式永远凑不满一格（空转到切窗口）。改成 CAS 原子扣减：同方向、不超量。

**6. `Start/Stop` 没同步。**
看门狗与「重启钩子」按钮可以同时通过检查、各装一个 `WH_MOUSE_LL` —— 滚动速度翻倍 + 句柄泄漏。加了生命周期锁。

## 三、更新链路

**7. 更新后重启会被单实例踢掉。** 新进程抢命名互斥体（超时 0），旧进程要等关闭流程（几百毫秒）才释放 —— 输的那次"窗口和图标一起消失"。现在先交还互斥体再拉起新进程。

**8. 发布脚本给的是启动器的 SHA256，而更新器校验的是主程序。** 写进发版说明就会让每次更新都"校验失败"；不写就只比体积、界面还显示"校验通过"。现在两个哈希都算、把**主程序**那份写进 `SHA256.txt`，发版脚本复核后拼进说明；客户端也优先读 GitHub 资产自带的 `digest`。

**9. `ApplyUpdate` 同一会话第二次必失败。** 备份名固定 `.old`，而它正是当前运行的映像。改成唯一名，并检查回滚结果（以前回滚失败也说"已回滚"）。启动时只清 `.old*`，`.new` 留给断点续传。

**10. `--featurecheck` 经启动器调用时永远 rc=0。** 它不在"跑完就退出"白名单里，启动器不等、直接返回。已补齐（featurecheck / wheeltest / scrollsmooth）。

## 四、启动器与数据目录

**11. 干净机器上「缺 .NET」对话框永远不出现。** 判据要求 dotnet 根目录**存在**，而没装过的机器上它根本不存在 → 判 Unknown → 放行，用户看到的是 apphost 的英文报错。现在"root 不存在但父目录可读"算 Missing；首屏也直接给「仍然启动试试」（以前要先点一次「重新检测」才出现）。

**12. 装到 Program Files 时设置静默全丢。** 启动器无条件把 `MWE_DATA_DIR` 钉在安装目录，而主程序只看请求、不看能不能写 —— "不可写就退到 %APPDATA%"这条保障在唯一正常入口上被绕过了。现在两边都做写探测。

## 五、顺手修掉的

- 开机自启（注册表 Run 项）会写进版本目录 → 升级后静默失效；补上守卫（和计划任务那条一致）。
- 诊断包原样打包 `config.json`（DPAPI 不可用时令牌是明文）→ 打包前脱敏；日志按 `FileShare.ReadWrite` 拷贝（以前恰好在写日志时会整包失败）。
- 标题缓存"一个窗口只取一次"→ 浏览器切标签页后标题正则判错；改成 1 秒 TTL + `SendMessageTimeout(40ms)`，目标线程卡住也不会把钩子拖死。
- 名单页/关于页的操作提示写到了「更新」页的控件上（用户完全看不到）；统一走底栏。
- 隐式 `TextBlock` 样式无条件设 Foreground，把危险色/次级灰/选中色全顶成正文色 —— 「清除」「✕」、导航项的 hover/选中这才真正有颜色。
- `--smoke` 改用临时数据目录（以前会覆盖用户真实的 GitHub 令牌）；小屏窗口尺寸收敛；退出加二次确认；OSD 关窗停表；配置读取允许"数字写成字符串"。
- `--scrollsmooth` 的"速度抽搐"判据过滤掉 <4ms / <1px 的采样抖动（之前同一版代码 2/4 次误报，现在 4/4 稳定通过）。
