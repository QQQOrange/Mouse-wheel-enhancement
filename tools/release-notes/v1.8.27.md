# v1.8.27：更短的跟手延迟 + 更长的惯性 + 二阶速度低通

三处一起改，目标是"手指到哪、内容到哪"。

## 1. 速度低通做成二阶

上一版只有一级（14ms 不够抹平就会延迟，22ms 又太黏）。这一版**两级串联、各 14ms**：

- 第一级抹掉"档到档"的速度尖峰；
- 第二级抹掉**加速度**的跳变（一阶系统在档来的瞬间仍有一个加速度阶跃，敏感的人能读作"轻轻一顶"）。

两级之后速度与加速度都连续。

## 2. 默认手感向触控板靠（schema 8 迁移）

| 参数 | 旧默认 | **新默认** | 为什么 |
|---|---:|---:|---|
| 跟手 τ | 45 ms | **30 ms** | 45ms 的滞后读作"发飘"；触控板是手到哪内容到哪 |
| 惯性 | 180 ms | **420 ms** | 收尾拉长，配合二阶低通是连续收敛，不是软着陆 |

**只改仍是旧默认值的用户**（45/180），自己调过的一律不动。

## 3. 实测

| 指标 | v1.8.26 | **v1.8.27** |
|---|---:|---:|
| 中段脉动 | 1.3~1.8× | **1.5~1.6×** |
| 单帧突刺 | 1.3× | **1.2~1.3×** |
| 整段帧数（8 格） | 66~68 | **63** |

总位移依然一像素不差（705.5 px / 8 格 = 88.2 px/格）。

## 想更极端

平滑滚动页 → 手感曲线 → **触控板**（τ 16ms / 惯性 600ms），再叠加**细腻模式**（量化 0.5px → 0.17px），
这就是当前模型能给到的极限。
