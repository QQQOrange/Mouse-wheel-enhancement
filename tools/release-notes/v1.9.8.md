# v1.9.8：把 v1.9.6 / v1.9.7 的内容正式打成一个版本

上一版发 v1.9.7 时，仓库 tag 指向了一个旧提交（远端被几次 API 推送搞得有点乱），
所以这次重新打包发布，确保 **tag、源码、exe 三者一致**。

## 本版包含

**功能**
- 横向滚动平滑（Shift+滚轮拆成最多 8 个事件摊发，独立线程，不影响纵向）
- 中键拖拽平移（`input.middleDragPan`，默认关闭，40px = 1 格）
- UI 像素基线回归（`--uibase` / `--uicheck`，0.3% 容差 + 热区）
- beta / stable 更新通道（`updateChannel`）

**修复**
- 守护进程启动即还原 → 细腻模式刚开就被打回 3 行（已修）
- 横向线程 Stop/Start 后静默失效（已修）
- 中键拖拽锚点用 0 当哨兵、关闭后状态未清（已修）
