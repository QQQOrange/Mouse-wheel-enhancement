# v1.9.7：修 3 个 bug（都出在上一版新代码里）

## 1. 守护进程"启动就还原"（严重）

`SpawnGuard` 之后，守护进程第一行就调了 `RestoreLines`，而主进程此刻正在用细腻模式（系统=1 行）。
它会把行数立刻写回 3，导致细腻模式刚开启就被打回去 —— 开启/关闭表现随机。
现在守护进程只等主进程退出，**退出后**才还原。

## 2. 横向线程 Stop/Start 后静默失效

`_hThread ??=` 只在第一次赋值；动画器 Stop/Start 之后 `_alive` 变过，线程已退出但字段非空，
于是横向滚动再也起不来（且没有任何报错）。
现在线程跟着 Start() 一起起、退出时把字段清空。

## 3. 中键拖拽两处

- 锚点用 `_panAnchorY == 0` 当"未初始化"标记：屏幕 Y=0 时每帧都会重置锚点，拖不动 → 改成独立 `_panHasAnchor`。
- 功能中途关闭时 `_panActive` 没清，下次打开会莫名吞掉第一次中键抬起 → 关闭时一并清状态。
